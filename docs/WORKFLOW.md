# Application Workflow

## Patient booking
1. Open the application.
2. Browse doctor profiles and specialties.
3. Select a doctor and appointment date.
4. Review available slots.
5. Enter required patient details.
6. Submit the booking.
7. Receive success or conflict feedback.

## Cancellation
1. Open upcoming appointments.
2. Select an appointment.
3. Confirm cancellation.
4. Mark the appointment as Cancelled.
5. Make the slot available for another booking.

## Doctor workflow
View the daily schedule and manage unbooked availability.

## Receptionist workflow
Search/select a patient, choose a doctor and available slot, then create or cancel an appointment.

These workflows describe intended behavior; mark them implemented only after development and testing.
